🗄️ 创建 rejected_annotations 表

📋 说明

这个页面用于检查和创建 rejected_annotations 表，该表用于记录所有被质检打回的标注数据。

功能：

  • ✅ 创建表结构（包含标注人、质检人、打回原因等字段）
  • ✅ 创建索引以提高查询性能
  • ✅ 设置 RLS 安全策略
  • ✅ 迁移现有被打回的数据

🔧 手动创建步骤（推荐）

  1. 打开 Supabase Dashboard
  2. 进入 SQL Editor
  3. 打开项目中的 CREATE_REJECTED_ANNOTATIONS_TABLE.sql 文件
  4. 复制所有SQL代码，粘贴到 SQL Editor 中
  5. 点击 Run 执行
  6. 回到此页面，点击"检查表是否存在"确认
