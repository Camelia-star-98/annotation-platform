🔍 调试标注文件名显示问题

检查数据库中的 annotation_file_name 字段

ℹ️ 问题描述：
用户反馈："标注文件名没展示出来"
可能的原因：
1. 数据库中 annotation_file_name 字段不存在
2. 数据库中的数据没有 annotation_file_name 值
3. 前端查询时没有包含这个字段
4. 前端渲染逻辑有问题

🗄️ 检查1：数据库字段是否存在

检查 videos 表中是否有 annotation_file_name 字段

📊 检查2：数据统计

统计有多少视频有 annotation_file_name 值

🎯 检查3：用户提到的视频

查看用户截图中的几个视频是否有标注文件名

💻 检查4：模拟前端查询

模拟质检管理页面的数据查询，看看是否能获取到 annotation_file_name
