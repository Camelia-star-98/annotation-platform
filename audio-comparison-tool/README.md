# 音频对比工具 Demo

这个工具可以帮助您检测音频中的读音问题，对比标准发音和实际发音的差异。

## 功能特点

1. **语音识别** - 使用 Whisper 将音频转为文本
2. **发音评估** - 对比两段音频的相似度
3. **可视化分析** - 显示音频波形和频谱对比
4. **问题检测** - 标注可能存在问题的读音片段

## 使用的开源模型

### 1. OpenAI Whisper
- **用途**: 语音识别，转录音频内容
- **优势**: 多语言支持，准确度高
- **模型大小**: tiny(39M), base(74M), small(244M), medium(769M), large(1550M)

### 2. wav2vec2-base-960h (Facebook)
- **用途**: 音素识别和发音分析
- **优势**: 可以检测细粒度的发音差异

### 3. SpeechBrain
- **用途**: 语音嵌入提取，计算音频相似度
- **优势**: 通用语音工具包，功能丰富

### 4. librosa + soundfile
- **用途**: 音频处理和特征提取
- **优势**: Python生态系统中最流行的音频处理库

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

### 基础用法
```bash
python audio_comparison.py --reference 标准音频.wav --target 待检测音频.wav
```

### Web界面
```bash
python app.py
```
然后在浏览器中访问 http://localhost:5000

## 输出结果

工具会生成以下分析结果：

1. **文本转录对比** - 显示两段音频的文字内容
2. **相似度评分** - 0-100分，分数越高表示越相似
3. **问题片段标注** - 标出读音可能有问题的时间段
4. **可视化图表** - 波形和频谱对比图

## 技术原理

1. **音频预处理**: 降噪、归一化、重采样
2. **特征提取**: MFCC、梅尔频谱、音素特征
3. **对比分析**: DTW(动态时间规整)、余弦相似度
4. **问题检测**: 基于阈值的异常检测
