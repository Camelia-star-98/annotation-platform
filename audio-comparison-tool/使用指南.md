# 音频对比工具

这是一个基于AI的音频对比工具，可以帮助检测读音问题。

## 快速开始 (简易Demo)

如果你只是想快速了解工具的工作原理，无需真实音频文件：

```bash
# 1. 安装最小依赖
pip install -r requirements_minimal.txt

# 2. 运行简易demo
python simple_demo.py
```

这将生成两个示例场景的可视化结果。

## 完整安装 (推荐)

使用真实音频文件和完整功能：

### 方法1: 使用Web界面 (最简单)

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动Web服务
python app.py

# 3. 打开浏览器访问
# http://localhost:5000
```

### 方法2: 命令行使用

```bash
# 对比两个音频文件
python audio_comparison.py --reference 标准音频.wav --target 待检测音频.wav

# 使用更大的模型提高准确度
python audio_comparison.py -r 标准.wav -t 测试.wav --model medium

# 自定义输出文件名
python audio_comparison.py -r 标准.wav -t 测试.wav --output my_result
```

### 方法3: 作为Python库使用

```python
from audio_comparison import AudioComparisonTool

# 初始化工具
tool = AudioComparisonTool(whisper_model_size='base')

# 对比分析
result = tool.compare('标准.wav', '测试.wav', output_prefix='result')

# 查看结果
print(f"相似度: {result['overall_similarity']:.2f}/100")
print(f"评价: {result['assessment']}")
```

## 功能特点

✅ **语音识别** - 使用OpenAI Whisper转录音频内容  
✅ **发音评估** - 基于MFCC和DTW算法对比音频相似度  
✅ **问题检测** - 自动标注读音可能有问题的时间段  
✅ **可视化分析** - 生成波形和频谱对比图  
✅ **Web界面** - 用户友好的拖拽式上传界面  
✅ **命令行工具** - 支持批量处理  

## 使用的开源模型

1. **OpenAI Whisper** - 语音识别
   - 多语言支持 (中文、英文等)
   - 多种模型大小可选
   - 高准确度

2. **DTW (Dynamic Time Warping)** - 时序对齐
   - 处理不同语速的音频
   - 精确的特征对比

3. **librosa** - 音频特征提取
   - MFCC特征
   - 梅尔频谱
   - 音频预处理

## 输出结果

工具会生成以下文件：

- `*_comparison.png` - 可视化对比图(波形 + 频谱)
- `*_analysis.json` - 详细分析数据(JSON格式)

JSON包含:
- 转录文本对比
- 整体相似度分数(0-100)
- 问题片段列表(时间戳、严重程度)
- 综合评价

## 常见问题

**Q: 第一次运行很慢?**  
A: Whisper模型首次使用时需要下载，base模型约74MB。

**Q: 支持哪些音频格式?**  
A: WAV, MP3, OGG, FLAC, M4A等常见格式。

**Q: 如何提高准确度?**  
A: 使用更大的模型(medium/large)，确保音频质量好。

**Q: 可以处理多长的音频?**  
A: 建议单个音频不超过10分钟，过长建议分段处理。

## 技术原理

1. **音频预处理**: 重采样至16kHz，降噪处理
2. **语音识别**: Whisper模型转录为文字
3. **特征提取**: 提取MFCC特征(13维)
4. **时序对齐**: DTW算法对齐两段音频
5. **相似度计算**: 基于特征距离计算0-100分数
6. **问题检测**: 滑动窗口分段分析，标注低相似度片段
