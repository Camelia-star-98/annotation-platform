## 常见问题排查

### 1. 模块未安装

**症状：** `ModuleNotFoundError: No module named 'xxx'`

**解决：**
```bash
# 对于简易demo
pip3 install -r requirements_minimal.txt

# 对于完整功能
pip3 install -r requirements.txt
```

### 2. 权限问题

**症状：** `Permission denied`

**解决：**
```bash
# 给脚本添加执行权限
chmod +x start.sh

# 或者使用 python3 直接运行
python3 simple_demo.py
```

### 3. 端口被占用

**症状：** `Address already in use`

**解决：**
```bash
# 查找占用5000端口的进程
lsof -i:5000

# 杀掉该进程
kill -9 <PID>

# 或者修改端口（在app.py中修改port参数）
```

### 4. Whisper模型下载慢

**症状：** 第一次运行时卡住很久

**原因：** 正在从网络下载Whisper模型

**解决：**
- 耐心等待（只需下载一次）
- 使用较小的模型（tiny或base）
- 检查网络连接

### 5. Flask模板找不到

**症状：** `TemplateNotFound`

**解决：**
```bash
# 确认文件结构正确
ls -la templates/

# 应该能看到 index.html
```

## 推荐的使用流程

### 第一次使用（了解功能）

1. **运行简易demo**
   ```bash
   pip3 install numpy scipy matplotlib dtw-python
   python3 simple_demo.py
   ```

2. **查看生成的图片**
   - `demo_scenario1_good.png` - 良好发音示例
   - `demo_scenario2_issues.png` - 问题发音示例

### 进阶使用（真实音频）

1. **安装完整依赖**
   ```bash
   pip3 install -r requirements.txt
   ```

2. **准备音频文件**
   - 标准音频（如：native_speaker.wav）
   - 待检测音频（如：my_recording.wav）

3. **命令行分析**
   ```bash
   python3 audio_comparison.py \
       --reference native_speaker.wav \
       --target my_recording.wav \
       --model base
   ```

### Web界面使用

```bash
# 启动服务
python3 app.py

# 浏览器访问
http://localhost:5000

# 上传两个音频文件进行对比
```

## 文件说明

| 文件名 | 用途 | 是否必需 |
|--------|------|---------|
| `simple_demo.py` | 无需真实音频的演示 | 推荐首次运行 |
| `audio_comparison.py` | 核心功能，命令行工具 | 使用真实音频时必需 |
| `app.py` | Web界面后端 | 使用Web界面时必需 |
| `test_app.py` | Web服务测试 | 排查问题时使用 |
| `requirements_minimal.txt` | 最小依赖 | 运行demo需要 |
| `requirements.txt` | 完整依赖 | 完整功能需要 |
| `使用说明.html` | 使用文档 | 可直接在浏览器打开 |
| `start.sh` | 启动助手脚本 | 可选，方便使用 |

## 依赖安装详解

### 最小依赖（约50MB）
```bash
pip3 install numpy scipy matplotlib dtw-python
```
用途：运行 `simple_demo.py`

### 完整依赖（首次下载较大）
```bash
pip3 install -r requirements.txt
```
包含：
- Whisper (首次使用会下载模型)
- PyTorch (较大，约500MB+)
- librosa (音频处理)
- Flask (Web服务)
